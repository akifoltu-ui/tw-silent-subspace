# tw-silent-subspace
Reproduction code for 'The dimension of silent subspaces in finite-sampling truncations of the Weil quadratic form' (Zenodo 10.5281/zenodo.22730006).

## Lean 4 formal verification

All six results of the paper are machine-checked in Lean 4 / Mathlib, axiom audit clean, with negative controls. See [lean/README.md](lean/README.md). Reproduction log of this release: `run_AB_canli.log`.
